# cafe-landing
صفحة تعريفية لكافيه وهمي، عملتها كمشروع تدريبي لأثبت مهاراتي في تطوير المواقع.  فيها قائمة مشروبات وحلويات مقسّمة بتصنيفات، وكل ما تضيف صنف للطلب بيظهر بإيصال جنبها وبيتحدّث المجموع مباشرة، مع إمكانية زيادة الكمية أو إنقاصها. الصفحة متجاوبة وبتشتغل بشكل سليم على الجوال والكمبيوتر.  الأدوات: HTML وCSS وجافا سكريبت.
